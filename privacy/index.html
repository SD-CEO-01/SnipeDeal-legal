Privacy Policy

How SnipeDeal handles account, coupon, comparison, community-submission and service data while keeping checkout data deliberately limited.

Effective date: 10 September 2026 · Questions? support@snipedeal.co

1. What SnipeDeal is

SnipeDeal is a shopping-assistance website and browser extension that can find and test discount codes and compare exact-product prices when you intentionally ask it to. SnipeDeal is independently owned and operated. Retailers and affiliate networks do not own or operate SnipeDeal unless we expressly say otherwise.

2. Account information

If you create a SnipeDeal account, we store the name and email address you provide together with authentication records needed to operate your account. Passwords are handled through our authentication system and are not stored as readable plain text.

We may also store information associated with features you intentionally use while signed in, such as watchlist items, price-history information, price-alert records and a savings goal. Authentication sessions may include technical information such as session tokens, expiry times, IP address and user-agent information for security and account operation.

3. Coupon and checkout data

SnipeDeal uses coupon and deal information from sources such as participating merchants, authorised data or affiliate partners, public sources and community submissions to build and maintain its codes database.

When you intentionally run SnipeDeal at checkout, the extension may process the retailer page and checkout information locally as necessary to identify a coupon field, test a code and determine whether the checkout total changed. SnipeDeal may send a minimal coupon-validation result consisting only of the retailer domain, coupon code tested and whether it worked. This helps rank useful codes and retire repeatedly failing codes.

If you use the optional “Got a code SnipeDeal missed?” controls, pressing Test code tests the code against the current checkout, while pressing Submit code intentionally sends the retailer domain and the code you supplied so it can be stored as an unverified community candidate. Entering a code does not submit it by itself, and community submission alone does not mark a code as verified.

Coupon-validation telemetry is not designed to include your cart contents, product list, checkout total, payment-card details, shipping address, email address, retailer password, full checkout URL, SnipeDeal account information or a persistent extension installation identifier.

4. Exact-product comparison and community submissions

After you intentionally run SnipeDeal, the extension may send product information needed to perform an exact-product comparison. Depending on what the retailer page exposes, this can include a product name or identifier, the source retailer or domain, currency and price context needed to compare the current offer with other retailer listings. This comparison request is separate from the minimal coupon-validation telemetry described above.

Exact-product comparison requests are handled through SnipeDeal's comparison service hosted on Vercel and may use SerpApi to retrieve shopping-search data. These services process the comparison request so SnipeDeal can return retailer results. SnipeDeal is not designed to send payment-card details, retailer passwords or shipping addresses to the comparison service.

If you use the optional “Found it cheaper somewhere else?” feature, nothing is submitted until you paste or type a public product URL and press Submit link. A submission may include the URL you supplied together with current-product context such as product name, source URL or retailer, source price and currency so the candidate can be checked. Community submissions may be retained in SnipeDeal's moderation queue and are not shown to other shoppers as verified results until they pass verification.

5. Extension install and operational data

To count extension installations and recognise repeat install/update pings without creating duplicate install records, the extension generates a random installation UUID and may send that identifier together with the extension version. The install service may also record the request user-agent. This operational install record is separate from coupon-validation telemetry and is not designed to contain your browsing history, cart contents or payment information.

SnipeDeal may also store limited local extension state needed to operate features you request, such as settings, local Wishlist data, assisted-session state and result state.

6. Data we do not need

SnipeDeal is not designed to collect your retailer passwords, payment-card details, shipping addresses or complete browsing history. Checkout information needed to test a coupon or identify an exact product is processed only as necessary to perform the action you requested.

7. Email and weekly digest

If you opt in to SnipeDeal email, we store the email address you provide and subscription state needed to deliver and manage those messages. We use Resend as an email-delivery provider.

Weekly digest emails include an unsubscribe link. Following that link can update your digest preference without requiring you to sign in. The link contains a signed subscription token designed only to identify the subscription being changed.

If you unsubscribe, you may optionally tell us why. We may store the reasons you select and any text you voluntarily provide so we can improve the digest. We may retain limited suppression information so that an unsubscribe request remains honoured.

8. How we make money

SnipeDeal is free to install and use. We may earn an affiliate commission when you intentionally choose to use an eligible deal or retailer link SnipeDeal surfaced. The merchant pays that commission; it does not add a SnipeDeal fee to your purchase.

Affiliate attribution is triggered only by intentional user action. SnipeDeal does not silently rewrite shopping URLs in the background. Our active commercial relationships are described in the Affiliate Disclosure.

When you intentionally follow an eligible affiliate action, the retailer or affiliate network may process referral identifiers, link parameters, cookies or similar attribution technology under its own terms and privacy practices.

9. Hosting, search and service providers

The main SnipeDeal website is deployed using Netlify and is intended to be served through snipedeal.co. SnipeDeal's exact-product comparison API is hosted using Vercel, and comparison searches may be processed using SerpApi. We use Resend for email delivery. SnipeDeal may also use GitHub Pages to publish a static copy of its legal, privacy, disclosure and support information.

Database, authentication, hosting, email, comparison, affiliate and other infrastructure providers may process limited technical or service data where necessary to operate the functions for which they are used. We do not sell personal information to these providers for their own advertising purposes.

10. Cookies and local storage

SnipeDeal does not use advertising cookies to sell or profile your browsing activity. The website uses technically necessary authentication/session storage and its infrastructure may process request information needed to operate and secure the service.

The extension uses browser local or session storage for settings and other extension data needed to operate features. Retailer websites and affiliate networks may set their own cookies under their own privacy policies when you interact with them.

11. Data retention and deletion

Signed-in customers can request account deletion from their profile. Account deletion removes the Better Auth customer identity, sessions and credential records and deletes SnipeDeal account data currently linked by that user ID, including watchlist items, related price history and price alerts, and the yearly savings goal.

Operational records, community submissions, coupon intelligence or information that is not tied to the account user ID may have different retention periods. We may retain information reasonably needed to operate verification and anti-abuse systems, honour an unsubscribe request, address security or fraud, resolve disputes, or comply with applicable law. You may contact us about a privacy or deletion request using the details below.

12. Chrome Web Store Limited Use

SnipeDeal's use of information received through Chrome extension APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

SnipeDeal uses such data only to provide or improve its disclosed shopping-assistance functionality, does not sell it or use it for personalised advertising, and transfers it only where necessary to provide user-requested features, operate or secure the service, comply with applicable law, or as otherwise permitted by the Chrome Web Store User Data Policy.

13. Children

SnipeDeal is not directed at children. If a parent or guardian believes a child has provided personal information to SnipeDeal, contact us at support@snipedeal.co so we can review and address the request.

14. Your privacy requests

You may contact SnipeDeal to request access to, correction of, or deletion of personal information we hold about you, subject to applicable law. Account holders can also use the Delete account control within their profile.

15. Privacy complaints

If you have a complaint about how SnipeDeal has handled personal information, contact us first at support@snipedeal.co. If you remain dissatisfied, you may be able to raise the matter with the Office of the Australian Information Commissioner (OAIC).
